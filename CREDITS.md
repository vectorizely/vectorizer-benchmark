## In the page's results, not here

The results on vectorizely.com/vectorizer-benchmark (2026-10-05, `published/`) were measured on
a different set of 20: the nine images above the Commons table, and eleven that came from
[Pixabay](https://pixabay.com/) under the Pixabay Content License. That license allows using and
adapting an image but not distributing it on its own in the form Pixabay serves it, so those
eleven are not in this repository. `published/images-2026-10-05.json` names them. The set here
swaps them for the Commons files above, so that all 20 can be shared.
